Independent harmonic-chain comparison, 7 October 2026.

This implementation compares the pure harmonic-chain TFD with the Gaussian product of its exact left/right marginals. It uses direct covariance evolution and Gaussian entropies, without channel fitting, decoding, or any code from the paper's simulations. The manuscript and its figures have not been modified. This is an independently specified realization of the written protocol; the original simulation code was not available to compare numerically.

Run from the project root:

```sh
OPENBLAS_NUM_THREADS=1 python independent_protocol/harmonic_protocol.py
OPENBLAS_NUM_THREADS=1 python -m unittest discover -s independent_protocol -v
```

NumPy, SciPy, and Matplotlib are required and are already installed in this environment. The versions used were NumPy 2.4.4, SciPy 1.17.1, and Matplotlib 3.10.9. No installation is needed. The thread setting avoids excessive BLAS overhead for small matrices.

**Conventions and defaults.**

The covariance is `V_ij = <{Delta R_i,Delta R_j}>/2`, with hbar=1 and vacuum covariance I/2. Means vanish. Entropies and mutual information use natural logarithms and are reported in nats. Divide by log(2) for bits, or by `2 S(obs)` for normalized MI.

All arrays use **interleaved** quadratures, `(x_0,p_0,x_1,p_1,...)`. Resource modes are ordered `L0,...,L(N-1),R0,...,R(N-1)`. After insertion the ordering is `observer,L0,...,L(N-1),R0,...,R(N-1)`. The manuscript often uses all positions followed by all momenta, so permute arrays before comparing them directly.

| Parameter | Default |
|---|---|
| Modes per side N | 10 |
| Boundary conditions | Periodic ring, N>=3 |
| Onsite frequency squared m² | 13 |
| Spring constant k | 5 |
| Inverse temperature beta | 1 |
| Coupling strength eta | 1 |
| Observer–input TMS squeezing | r=1 |
| Probe quadrature reference frequency | 1 |
| Insertion site | L0 |
| Excluded coupling pair | L0,R0 |
| Fixed modular evolution time for coupling scan | 3 |
| Coupling scan | 0 to 16, 321 points |
| Evolution scan | 0 to 15, 301 points |

N, eta, probe squeezing, probe reference frequency, and scan choices are explicit assumptions rather than a claim to reproduce all parameters of a particular manuscript figure. The oscillator Hamiltonian is

\[
H_{\rm hc}=\frac12\sum_{j=0}^{N-1}\left[p_j^2+m^2x_j^2+k(x_j-x_{j+1})^2\right],\qquad x_N=x_0.
\]

The isolated forward/backward evolution is generated by the modular Hamiltonian `K=beta H_hc`. The coupling step includes both local **physical** Hamiltonians and the inter-side interaction:

\[
H_c=H_L+H_R+\frac{\eta}{4}\sum_{j\ne0}
\left(\omega_0 x_{Lj}x_{Rj}+\frac{p_{Lj}p_{Rj}}{\omega_0}\right),
\qquad\omega_0=\sqrt{m^2+2k}.
\]

This brackets both terms under the prefactor in the draft's coupling equation. The coefficient of `x_Lj x_Rj` is eta*omega0/4; the corresponding symmetric off-diagonal Hamiltonian-matrix entry has that same value. There is no additional factor of two. If the original code uses a different coupling normalization, match the coefficient before comparing the coupling-time axis. At beta=1, modular and physical local generators coincide. At other beta values, the convention above remains explicit.

The probe covariance in `(x_obs,p_obs,x_input,p_input)` is

\[
V_{\rm probe}=\frac12\begin{pmatrix}
c&0&s&0\\0&c&0&-s\\s&0&c&0\\0&-s&0&c
\end{pmatrix},\qquad c=\cosh(2r),\quad s=\sinh(2r).
\]

The default reference frequency is 1. `--probe-frequency w` applies the local rescaling `(x,p) -> (x/sqrt(w),sqrt(w)*p)` to both probe modes. This leaves their initial entanglement unchanged but changes the input's orientation and scale relative to the harmonic-chain quadratures. To match a probe defined with the local chain frequency, set this to `sqrt(23)` for the default mass and spring constant.

**The two preparations and common protocol.**

The code diagonalizes the ring potential matrix, constructs thermal covariances with `nu_k = coth(beta*omega_k/2)/2`, and constructs the pure TFD using cross-correlations `alpha_k = csch(beta*omega_k/2)/2`. The product control retains both complete marginal covariances and sets only the LR blocks to zero. Local energy, local entropy, and all local correlations are therefore identical. The control is unentangled across L:R; it need not be a product over individual oscillators within either side.

For each preparation, the code performs:

1. Backward modular evolution on L for time `t_evolve`.
2. Trace out the old L0 mode, replace it with the input half of the TMS, and retain the other half as an isolated observer. The old mode's correlations are discarded, not retained as an additional environment mode in the reported system.
3. Forward modular evolution on L for the same time.
4. Evolution of L+R under H_c for `t_couple`.
5. Forward modular evolution on R for `t_evolve`.

Both preparations always receive exactly the same operations and timings. No decoder is used for the MI calculations; the fidelity extension below also evaluates an output decoder. The observer is untouched. Since step 5 is local on R, it cannot change either whole-side MI, but it is implemented explicitly and this invariance is tested. Also, because H_c includes local spring dynamics, information can propagate and cross sides *during the coupling step*, even if `t_evolve=0`. That point on the evolution scan is not a no-dynamics control. Set eta=0 or the coupling duration to zero to eliminate inter-side communication.

The first scan fixes `t_evolve=3` and varies the coupling duration. Unless `--coupling-time` is supplied, the second scan uses the first TFD right-side MI peak with prominence at least 2% of `2S(obs)`. If there is no resolved interior peak, it uses the grid maximum and records that fallback. This is a stated one-dimensional grid prescription, not a global optimization. For the default run it selects `t_couple=6.5`, and that same duration is used for the product control. The second scan then varies `t_evolve` while holding that coupling duration fixed.

**Default results.**

At `t_evolve=3`, `t_couple=6.5`:

| Initial resource | I(obs:L) [nats] | I(obs:R) [nats] | I(obs:LR) [nats] |
|---|---:|---:|---:|
| TFD | 0.4008293694 | 2.8264630793 | 3.2396441858 |
| Product of marginals | 0.3997852731 | 2.7847453543 | 3.2396441858 |

The TFD raises right-side MI by 0.0417177251 nats at that common point, approximately 1.29% of the initial `2S(obs)`. The product control still transfers almost as much observer correlation to the right. Across the fixed-coupling evolution scan, the largest right-side difference is approximately 0.058006 nats at `t_evolve=3.85`; the difference is slightly negative at some early times. These observations apply to this parameter choice and diagnostic, and do not establish a statement about fidelity, quantum capacity, other temperatures, or all possible parameter optimizations.

The initial resources have the same `S(L)=S(R)=0.6101007459` nats and the same energy per side `24.1760152874`. The TFD has initial `I(L:R)=1.2202014917` nats, whereas the product has zero. Its relatively small initial entanglement at beta=1 is useful context when interpreting the modest difference.

`I(obs:LR)=2S(obs)=3.2396441858` nats is conserved after insertion; maximum observed drift across both scans and recorded stages was `2.52e-11` nats. **I(obs:L)+I(obs:R) need not equal I(obs:LR)**, so the two curves should not be treated as complementary probabilities or conserved shares. The difference plot is TFD minus product, not a separately normalized statistic.

**Validation.**

Fifteen tests check TFD purity and matching marginals; analytic modular evolution against a matrix exponential; thermal and two-sided TFD stationarity; discard-and-replace against an explicit larger-system SWAP and trace; entropy against the known thermal-mode formula; no signalling at zero eta; no transfer at zero coupling duration; no transfer when springs vanish and the insertion pair is excluded; conservation of observer covariance and total MI; invariance under final right-only evolution; resource-independent observer-output cross-covariances under fixed linear dynamics; coupling normalization and symplecticity; and rejection of an unphysical covariance. The site-resolved extension also tests the insertion-site MI, sitewise no signalling, ring translation/reflection symmetry, and two-mode symplectic eigenvalues against the alternative determinant-invariant formula. Some tests cover several related invariants.

Symplectic eigenvalues are computed using the Hermitian matrix `i L^T Omega L`, where `V=L L^T` is a Cholesky factorization. A symplectic eigenvalue more than `1e-8` below 1/2 raises an exception. Only smaller roundoff excursions are clipped. Each scan checks physicality through the entropy calculations and rejects total-MI drift above `1e-7` nats. The output's very small conservation error and limiting-case tests support the implementation; they are not a reproduction of unavailable original simulation code.

**Site-resolved comparison.**

Run the follow-up calculation with

```sh
OPENBLAS_NUM_THREADS=1 python independent_protocol/site_resolved.py
```

This loads parameters and the selected coupling duration from `results/summary.json`. It does not reoptimize the coupling or alter the initial resources. To use a different whole-side run, pass `--source path/to/summary.json --out path/to/site_results`. The optional `--evolution-points` changes the grid density. The default run scans 301 evolution times from 0 to 15 with coupling time 6.5.

The output is `I(obs:L_j)` and `I(obs:R_j)` for every site, both immediately after coupling and after the final right-side evolution. Each site MI is calculated from the observer–site two-mode reduction. **The sum of site MIs is not the whole-side MI** and must not be interpreted as an additive decomposition of the transmitted information.

For the defaults, site profiles are also very similar between TFD and product resources. Both exhibit pronounced refocusing at R0. At three common evolution times, after the complete protocol:

| Evolution time | Selection | TFD I(obs:R0) | Product I(obs:R0) |
|---|---|---:|---:|
| 3.000000 | Previous whole-side comparison point | 0.667192 | 0.680233 |
| 1.891803 | First resolved TFD receiver peak | 1.462264 | 1.468313 |
| 11.377678 | Strongest sampled TFD receiver peak, locally refined | 1.808120 | 1.795706 |

All MIs are in nats. Both preparations are evaluated at the same time in each row. Their own peak times are also saved in `site_results/summary.json`. The first peak is the first interior grid peak with prominence at least 2% of `2S(obs)`, refined within its neighboring grid interval. The strongest peak is obtained by refining around the largest sampled R0 value in [0,15]. Neither prescription certifies that no narrower peak was missed between grid points. The later peak should be distinguished from the first transfer/refocusing event in this finite ring.

At the first TFD receiver peak, the final right-only evolution increases I(obs:R0) from 0.576168 to 1.462264 nats for the TFD, and from 0.569996 to 1.468313 for the product resource. At the later peak the corresponding changes are 0.356818 to 1.808120 and 0.361299 to 1.795706. Whole-right MI is unchanged by this last local evolution. At t=3 the last evolution instead decreases R0 MI, and the strongest right-site signal lies at the symmetry-related sites R3/R7. Thus this last step visibly redistributes correlations, and its refocusing is present in both preparations.

Across all sampled sites and times, TFD-minus-product site MI ranges from about -0.03118 to +0.04360 nats. This parameter choice therefore does not reveal a large advantage from the initial LR correlations in either whole-side transfer or site-local refocusing. This conclusion is limited to these settings and to MI. The fidelity extension below supplies a separate comparison; reference-output entanglement is not quantified here.

**Fidelity comparison.**

```sh
OPENBLAS_NUM_THREADS=1 python independent_protocol/fidelity_comparison.py
OPENBLAS_NUM_THREADS=1 python -m unittest discover -s independent_protocol -v
```

The script uses the parameters and both scan grids from `results/summary.json`, with optional `--source` and `--out` paths. The target is the original pure observer–input two-mode squeezed state (r=1). The output is the observer–right-site reduced state after the complete protocol. This is a finite-energy entanglement-fidelity test, not an average over a coherent-state alphabet or a statement about every possible input.

For zero means, a pure target, and vacuum covariance I/2, the root convention is

\[
f=\operatorname{Tr}\sqrt{\sqrt{\rho_{\rm target}}\rho_{\rm out}\sqrt{\rho_{\rm target}}}
  =\det(V_{\rm target}+V_{\rm out})^{-1/4}.
\]

The squared convention is F=f². Both are saved, and figures use root fidelity. The determinant expression is the pure-target specialization of [Banchi, Braunstein and Pirandola's Gaussian fidelity formula](https://arxiv.org/html/1507.01941v1).

The script extracts the channel directly from the linear propagator:

\[
V_{\rm out}=X V_{\rm in}X^T+Y,\qquad
Y=B V_{\rm env}B^T.
\]

The environment covariance is evaluated after backward evolution and removal of the old insertion mode. Thus the TFD's surviving LR correlations are retained. The same X applies to both resources, but Y can differ. If C is the difference in their environment LR block, then

\[
\Delta Y=B_L C B_R^T+B_R C^T B_L^T.
\]

This term need not vanish. State-independent linear propagation fixes the signal matrix, not the noise covariance or the fidelity.

Both raw output fidelity and fidelity after the common one-mode symplectic decoder D=sqrt(det X) X⁻¹ are computed. For det X>0 this gives DX=sqrt(det X) I, removing the signal's deterministic rotation/squeezing while retaining its scalar gain. The decoder is identical for both resources and is **not optimized for fidelity** in the presence of anisotropic noise. It can decrease fidelity at some sites. For det X≤1e-12 or condition number above 1e10, this prescription is unavailable: decoded scores are NaN in CSV, null in JSON, and gaps in plots. Raw scores remain available. R0 has a defined decoder throughout the fixed-coupling evolution scan.

At the common coupling time 6.5, the R0 results are:

| Evolution time | Resource | Raw root fidelity | Decoded root fidelity | Decoded squared fidelity |
|---|---|---:|---:|---:|
| 3.0 | TFD | 0.34203651 | 0.44008941 | 0.19367869 |
| 3.0 | Product | 0.34277152 | 0.43767259 | 0.19155730 |
| 11.4 | TFD | 0.39115177 | 0.68418063 | 0.46810313 |
| 11.4 | Product | 0.39099246 | 0.67937700 | 0.46155311 |

Time 11.4 maximizes decoded R0 fidelity on the 301-point evolution grid for both preparations. It is a sampled maximum, without local refinement or joint timing/decoder optimization. Across that evolution grid, the TFD-minus-product decoded root-fidelity difference ranges from -0.00593217 to +0.00675459. The difference is small, resolvably nonzero, and changes sign. These settings show no large benefit from the initial LR correlations, but do not establish a general equality or an advantage at every time.

At t=11.4 the uncorrected noise matrices, in the original quadratures, are

\[
Y_{\rm TFD}=\begin{pmatrix}0.03971457&-0.00526568\\-0.00526568&0.89730292\end{pmatrix},\quad
Y_{\rm product}=\begin{pmatrix}0.04152164&-0.00173630\\-0.00173630&0.88484402\end{pmatrix}.
\]

Their difference is much larger than numerical roundoff. It is not positive or negative semidefinite, so interpreting the correlations as simply reducing all noise would also be inaccurate.

All **22 tests pass**, including seven fidelity tests: identity and exact symplectic decoding; an analytic TMS phase-flip overlap; a pure-loss result derived from the Fock expansion; the standard additive-noise Braunstein–Kimble expression; unavailable-decoder handling; mixed-target rejection; and channel extraction/probe independence. Across the full scans, channel reconstruction agrees with direct covariance propagation to within 1.78e-14. Every extracted channel satisfies the Gaussian complete-positivity condition, with minimum tested eigenvalue 0.001862. The original paper and figures are unchanged.
